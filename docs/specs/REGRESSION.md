# Прогон по образцам

Перед выпуском агент сам проходит сценарии в настоящем браузере на страницах-образцах. Образец изображает внешний сервис и ведёт себя предсказуемо, поэтому расхождение значит ошибку у нас.

## Что прогон доказывает

Что продукт на образцах ведёт себя по правилам. Прогон не заменяет ручную проверку: пользовательский взгляд на результат остаётся за человеком.

## Что прогон не доказывает

Ничего о живых сервисах. Ни один сценарий не открывает чужую страницу: на живом сервисе расхождение не отличить от сегодняшнего поведения этой страницы. Живой сервис проверяется отдельно, в браузерной полосе, и результат записывается как наблюдение, а не как норма.

## Как запускать

1. `npm run build`.
2. `npm run testserver` в фоне. Адрес по умолчанию `http://127.0.0.1:4173/`.
3. Для каждой строки таблицы открыть страницу, сделать то, что написано, прочитать статус и консоль.
4. Закрыть страницу до следующей строки: `docs/specs/BROWSER-LANE.md`.
5. Отчёт: строка таблицы, норма, наблюдение, отклонения словами поведения.

## Формат таблицы

Таблицу читает сторож, поэтому её формат нормативен. Четыре колонки. В «Составе прогона» в обратных кавычках имя страницы из каталога образцов. В «Норме» в обратных кавычках id перехода, которому принадлежит ответ. Каждая страница используется, каждое конечное состояние модели достигается хотя бы одним сценарием.

## Сценарии

| Сценарий | Состав прогона | Что делает прогон | Норма (владелец ответа) |
| --- | --- | --- | --- |
| Доставка доказана | `delivered.html` | Нажать Send, дождаться статуса | Статус `confirmed`, текст в ленте, в консоли `reminder.delivery-confirmed` |
| Принято, но не доставлено | `swallowed.html` | Нажать Send, ждать до 7 секунд | Статус `unconfirmed`, успех не показан, в консоли `reminder.delivery-unproven` |
| Провайдер отказал | `refused.html` | Нажать Send | Статус `failed`, в консоли `reminder.send-refused` |
| Перезапуск с неизвестным исходом | `restarted.html` | Нажать Send | Статус `duplicate-blocked`, в ленте пусто, в консоли `reminder.duplicate-blocked` |
