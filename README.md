# agent-harness

A project harness for building software with coding agents when nobody reads the diff. It moves checking from a human reading code to machines that fail loudly, and leaves the human to accept behaviour. Works with Claude Code and Codex. Node standard library only, MIT. Docs are in Russian; files agents read are in English.

---

Обвязка проекта для тех, кто строит продукт руками ИИ-агентов и не читает дифф. Она выделена из настоящего закрытого продукта, который делает один не-программист.

Обвязка не отменяет приёмку, она меняет её предмет. Правила, порядок действий и согласованность держат машины: нарушение роняет сборку. Человек принимает то, что видит пользователь. Границы описаны в `docs/SKELETON.md`.

## Посмотреть за три минуты

```sh
git clone https://github.com/yesgenius/agent-harness
cd agent-harness
npm install
npm run demo:guards
```

Нужен Node 25 (`.nvmrc`). Демонстрация ломает копию репозитория восемнадцатью способами и показывает, какая проверка остановила каждый. Рабочее дерево не меняется.

```text
поймано   Барьер выглядит на месте, но больше не отказывает
          the-push-barrier-guards-the-declared-release-branch.test.js
поймано   Проверка перестала видеть файлы и поэтому стала зелёной
          console-access-single-sink.test.js
поймано   Две строки поменяли местами: отправка раньше записи
          no-reminder-leaves-before-the-intent-is-recorded.test.js
```

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run build` | Все проверки и генерация документов |
| `npm test` | Сторожа и тесты примера, включая посаженные нарушения |
| `npm run demo:guards` | Демонстрация для человека |
| `npm run testserver` | Страницы-образцы для прогона в браузере |
| `npm run verify` | Сборка, тесты и проверка, что генерация ничего не изменила |

## Два предупреждения

**Без песочницы.** Настройки разрешают агенту выполнять команды без подтверждения: иначе нельзя выдать наряд и уйти. Список запретов ловит только перечисленные формы команд. Запускайте в отдельной среде. `docs/specs/AGENT-FRONT-ENDS.md` объясняет, как включить подтверждения.

**Упрощения.** Проверка консоли ищет слово в коде, очищенном от комментариев и строк, поэтому регулярное выражение с кавычкой может её запутать. Модель процесса хранится в JSON, чтобы обойтись без зависимостей, и `scripts/fsm/fsm-log-prefixes.js` сверяет только логи, а не константы. Для большого проекта это отправная точка.

## Что осталось в исходном проекте

Только то, что привязано к нему: упаковка и публикация конкретного продукта, выпуск правок конфигурации, блокировка занятого браузерного профиля, плагины и звуковые хуки. Если вам нужно что-то из этого, опишите агенту провал, который хотите остановить.
