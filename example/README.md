# Учебный пример

Крошечный процесс с необратимым шагом: напоминание уходит через внешнего провайдера, а отозвать его нельзя. Пример нужен, чтобы сторожа и прогон по образцам работали на настоящем коде. Провайдер выдуман. Когда обвязка переезжает в ваш проект, папка удаляется: `docs/ADOPT.md`, шаг 6.
