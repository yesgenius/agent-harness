# Пример

Крошечный процесс с необратимым шагом: напоминание уходит через внешнего провайдера, а отозвать его нельзя. Пример нужен, чтобы сторожа и прогон по образцам работали на настоящем коде. Провайдер выдуман. В свой проект пример не переносят: проверки настраивают на код этого проекта. Что поправить после этого, сказано в `docs/SKELETON.md`, раздел «Перенос в свой проект».
